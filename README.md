
# Sprint_6

Автотесты для учебного проекта QA Java

# Описание

Проект содержит модульные тесты для проверки работы ключевых компонентов Java-приложения.
Реализованы тесты с использованием JUnit и Mockito, а также отчёт о покрытии кода с помощью JaCoCo.
Цель — проверить корректность работы методов и обеспечить высокий процент покрытия тестами.

# Стек

- Java 11
- Maven
- JUnit 5
- Mockito
- JaCoCo
